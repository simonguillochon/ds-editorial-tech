# Patterns spécifiques portfolio

## Page Home

| Composant | Description |
| --- | --- |
| **Navigation bar** | Logo + nav links (Home / Work / Content) + theme toggle. Sticky, fond avec backdrop-blur subtil au scroll. |
| **Hero block** | Titre Display avec italiques sur mots-clés. Sous-titre Body L. CTA principal + CTA secondaire en lien. |
| **Bio block** | Photo (ratio 4:5, traitement noir et blanc ou crème) + bloc texte structuré (parcours en quelques lignes). |
| **Testimonial card** | Citation grande taille (H3 serif), auteur (nom + rôle + entreprise), photo optionnelle. **Composant clé — soigner.** |
| **Social link group** | LinkedIn + GitHub avec icônes Phosphor + label texte. |

## Page Work

| Composant | Description |
| --- | --- |
| **Activity card** | Composant flexible avec variants : `pro` / `teaching` / `volunteering` / `education`. Logo + rôle + dates + description courte + tags compétences. |
| **Timeline divider** | Séparateur par année (texte H4 + ligne fine). |
| **Skill chip** | Tag spécifique pour les compétences techniques et fonctionnelles. |

## Page Content

| Composant | Description |
| --- | --- |
| **Podcast feature** | Vedette pour « Le Métier Qui Rentre » — pochette + accroche + plateformes d'écoute. Ratio asymétrique (60/40) pour le mettre en valeur. |
| **Article card** | Cover ou couleur de fond + titre + extrait + date + source (Ippon, autre blog). |
| **Talk card** | Event + lieu + date + lien éventuel (slides ou replay). |
| **Reading list item** | Couverture livre + titre + auteur + commentaire personnel court. |
| **Interest tag** | Tag éditorial avec parfois une icône Phosphor associée. |
