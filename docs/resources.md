## Inspirations de référence

- [Vercel](https://vercel.com) — sobriété tech, accent ponctuel, dark mode
- [Linear](https://linear.app) — densité d'information maîtrisée, micro-typographie
- [Apple](https://apple.com) — pureté, hiérarchie sans bruit
- [Hermès](https://hermes.com) — usage d'une couleur signature forte sur base sobre
